Final Year Project · B.E. CSE · May 2025

Smart Trolley with Autocheckout & Theft Detection

An IoT-enabled shopping trolley that removes the checkout queue: customers scan products as they shop, the bill updates in real time, and a load cell guards against unscanned items.

How it works

  • Scan Each item is scanned with the attached barcode scanner as it goes into the trolley.
  • Bill Price and weight appear instantly on the LCD screen and in the Blynk mobile app, so the bill is always up to date.
  • Guard A load cell tracks weight changes. If something is added without scanning, the buzzer alerts the customer and store staff.
  • Exit After successful payment the trolley unlocks. If payment is incomplete, an alarm prevents it leaving the store.

Built with

  • NodeMCU ESP8266
  • Barcode Scanner
  • Load Cell
  • Buzzer
  • LCD Display
  • Blynk App
  • Arduino Uno

Why it matters

Traditional billing causes delays and inconvenience in busy periods. Automating scanning removes manual counter work, cuts waiting time and reduces theft and billing errors.

Temperature & Humidity Monitoring System

A real-time data acquisition project using an Arduino Uno and a DHT11 sensor, with optional IoT integration for remote monitoring.

Procedure

  • Wire Connect DHT11 VCC to 5V, GND to GND and the data pin to digital pin 2 of the Arduino Uno.
  • Code Write the program in the Arduino IDE using the DHT library to read temperature and humidity.
  • Test Upload it and watch the readings on the Serial Monitor.
  • Go IoT Optionally send data over Wi-Fi to ThingSpeak or Blynk and monitor it remotely from a dashboard.

Built with

  • Arduino Uno
  • DHT11 Sensor
  • Breadboard & Jumper Wires
  • Arduino IDE
  • ThingSpeak / Blynk

Result

The system reads temperature and humidity from the DHT11 and displays accurate values on the Serial Monitor, for example 25.00 °C and 50.00 % humidity, and can be extended to remote cloud monitoring.
